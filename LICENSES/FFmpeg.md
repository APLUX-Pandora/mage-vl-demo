# FFmpeg license and source

The SDK includes two patched and separately namespaced FFmpeg implementations under LGPL-2.1-or-later. See the [LGPL 2.1 text](../sdk/lib/LICENSES/FFmpeg-COPYING.LGPLv2.1), [FFmpeg license notice](../sdk/lib/LICENSES/FFmpeg-LICENSE.md), and [patch provenance license](../sdk/lib/LICENSES/codec-video-prep-MIT.txt).

The [FFmpeg source bundle](../sdk/ffmpeg/ffmpeg-source.tar.xz) contains the upstream archive, patches, licenses, build scripts, and reference symbol maps. Follow the [rebuild and replacement instructions](../sdk/ffmpeg/README.md) to replace either shared library in your SDK or Python installation.
