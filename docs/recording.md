# Demo recording and footage credits

The [presentation recording](https://huggingface.co/APLUX-Pandora/Mage-VL/resolve/main/media/demo.mp4) illustrates editing the Analysis prompt, restoring its default and viewing streamed video-window descriptions. Generated descriptions can be inaccurate and are not scene annotations. For current controls and input limits, use the [Web guide](../demo/README.md).
